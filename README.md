# Mezo Photography

Modern responsive photography portfolio website for showcasing photography work and complete client sessions.

## Features

* Responsive and mobile-first design
* Photography portfolio with categories
* Complete client session galleries
* Cinematic slideshow
* Full-screen photo viewer
* Photo download
* Touch swipe support
* Smooth animations
* Arabic-first interface
